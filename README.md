# Self-Learning Agent

An experimental AI agent built from scratch to explore long-term memory, experience, reflection, and learning.

## Goal

Build an agent that does more than remember information.

The agent should be able to:

1. Perform tasks
2. Observe outcomes
3. Evaluate its performance
4. Learn from successes and failures
5. Store useful experiences
6. Retrieve relevant past experiences
7. Improve its behavior on future tasks

The project will prioritize understanding the underlying mechanisms over relying on high-level agent frameworks.
